## Structure

Two independently deployable pieces:

- `api/` — NestJS + TypeScript backend (REST API)
- `app/` — Vite + React + TypeScript frontend (SPA, no SSR)

## Getting started

Install dependencies — from the repo root if a `pnpm-workspace.yaml` exists (`pnpm install`),
otherwise separately in `api/` and `app/` (`pnpm install` in each).

<!-- @inikitty:inject:setup-steps -->

Then start both dev servers:

```bash
cd api && pnpm dev   # http://localhost:3000 (Swagger docs at /api/docs)
cd app && pnpm dev   # http://localhost:5173
```
